UPS

Create an app at developer.ups.com, add the Rating API product, and copy the Client ID and Client Secret. The account number is your 6-character UPS shipper number.

FedEx

Create a project at developer.fedex.com, enable the Rates and Transit Times API, and copy the API Key and Secret Key. The account number is your 9-digit FedEx account.

Settings are stored only on this PC in data/settings.json. Secrets are never shown again after saving; leave a secret field blank to keep the saved value.
